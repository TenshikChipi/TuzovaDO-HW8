## Запуск

Проекты используют .NET 7 и не требуют сторонних пакетов. Из корня репозитория:

```sh
dotnet build HW8/HW8.sln
dotnet run --project HW8/Task4
dotnet run --project HW8/Task5
dotnet run --project HW8/Task6
```

В задаче 5 `save.json` записывается рядом с исполняемым файлом, обычно в `HW8/Task5/bin/Debug/net7.0/`.

При первом запуске задачи 6 нужно ввести имя, сложность от 1 до 3 и громкость от 0 до 100. При повторном запуске приложение выводит сохранённые настройки без нового ввода. Для повторного ввода можно удалить `settings.json` из `HW8/Task6/bin/Debug/net7.0/`.

Пути к обоим JSON-файлам формируются через `Path.Combine(AppContext.BaseDirectory, ...)`. Папки `bin` и `obj` исключены из Git.
